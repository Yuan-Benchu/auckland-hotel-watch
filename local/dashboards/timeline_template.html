同一个入住日，价格随观测时刻怎么变。横轴是我去查的时间，不是入住日期——这是回答"什么时候下单更便宜"唯一有意义的画法。

数据订正：2026-09-16 13:50 之前的观测已全部作废

旧解析器的规则是"记住渠道名，之后遇到的任何金额都算它的，取最小值"。报价区没有正确收尾，一路读到了页面底部的促销文案：

[58] Super.com [59] $111 ← 真实房价 [60] Visit site [61] View more options from $121 [62] Track this hotel [63] Get emails about price changes [64] Save $33 if you stay Sep 20 – 21. ← 被当成了房价

Save $33 是促销省钱额。因为 33 < 111，Super.com 就被改写成了 NZ$33。新解析器只接受整行就是一个金额的行（$145、NZ$126），句子里的金额一律丢弃；已在 6 个页面上人工比对通过，0 条不一致。

作废的 – 条观测仍画在下面的图里（灰色虚线），好让你看见错误本身；它们不参与任何统计。

逐晚订房方案

每一晚各家里最便宜的那个。Google 上连住越长越贵也越难订——实测 1 晚 NZ$81、2 晚 87、3 晚 90、7 晚 110、30 晚 98，而 5/14/21 晚根本没有报价。 所以碎订就是最省的订法。
